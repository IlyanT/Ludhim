# Ludhim Transport & Logistiques

Site vitrine de Ludhim Transport & Logistiques, spécialisé dans le transport express, les courses dédiées et la sous-traitance depuis le Grand Est vers la France et l'Europe.

## Développement

```bash
npm install
npm run dev
```

## Publication

Le site est automatiquement construit et publié sur GitHub Pages lors de chaque mise à jour de la branche `main`.
